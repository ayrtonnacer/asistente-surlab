# Skall Bot Demo
Advanced AI-powered chatbot and demo application.
## Getting Started

This project is built with React, TypeScript, Vite, and Tailwind CSS.

### Prerequisites

- Node.js 18+
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/ayrtonnacer/skall-bot-demo.git
cd skall-bot-demo
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

### Build

To build for production:
```bash
npm run build
```

## Technologies

- **React** - UI library
- **TypeScript** - Type-safe JavaScript
- **Vite** - Fast build tool and dev server
- **React Router** - Client-side routing
- **Tailwind CSS** - Utility-first CSS framework
- **shadcn/ui** - Component library

## Deployment

This project is deployed to GitHub Pages. Any push to the main branch will automatically build and deploy the application.
